# 4. عملکرد رفت و برگشت امانت

## 4.1 حالت اول: قرار دادن امانت (Deposit)

| مرحله | عمل مکانیکی | محورهای درگیر | سنسور |
|-------|-------------|---------------|-------|
| 1 | کاربر امانت را روی نوار ورودی قرار می‌دهد | — | Presence Sensor Conveyor |
| 2 | نوار نقاله امانت را به سمت سینی می‌برد | Conveyor Roller | Conveyor Sensor |
| 3 | سینی در موقعیت Home (X=0, Z=0, Y=0) امانت را دریافت می‌کند | — | Tray Presence |
| 4 | سیستم خانه مقصد (مثلاً 06) را انتخاب می‌کند | — | — |
| 5 | گنتری به X=601.5mm (ستون 2) و Z=1003mm (ردیف 3) حرکت می‌کند | **X + Z هم‌زمان** | Endstop Feedback |
| 6 | Y به جلو (Y=450) — سینی به داخل خانه 06 می‌رود | **Y** | Y Endstop |
| 7 | سینی امانت را تخلیه می‌کند (لبه سینی + شیب 2° کف خانه) | Y (عقب‌نشینی) | Presence خانه 06 |
| 8 | Y به عقب (Y=0) برمی‌گردد | **Y** | |
| 9 | گنتری به Home یا ورودی بازمی‌گردد | **X + Z** | |

### جزئیات مرحله 7 — تخلیه کنترل‌شده

- کف هر خانه 2° شیب به سمت داخل دارد (یا سینی 2° شیب) تا امانت با جاذبه به داخل بلغزد.
- سینی Y به داخل رفته، سپس به عقب کشیده می‌شود در حالی که یک **Stopper ثابت** روی Z_Carriage جلوی امانت را می‌گیرد — امانت روی کف خانه می‌ماند، سینی خالی برمی‌گردد.
- این مکانیزم **Passive Ejector** نام دارد و بدون نیاز به موتور اضافی عمل می‌کند.

```
  Before:  [Tray+Parcel] ──Y=450──► [Compartment Floor]
  Eject:   Tray ◄──Y=0──  Stopper holds Parcel
  After:   [Parcel on Floor]  [Empty Tray returned]
```

## 4.2 حالت دوم: تحویل امانت (Retrieval)

| مرحله | عمل مکانیکی | محورها | سنسور |
|-------|-------------|--------|-------|
| 1 | کاربر خانه 06 را انتخاب می‌کند | — | UI Keypad |
| 2 | گنتری به X=601.5, Z=1003 می‌رود | **X+Z** | |
| 3 | سینی با Y=450 به داخل خانه می‌رود | **Y** | |
| 4 | سینی زیر امانت می‌رود (لبه جلویی 30mm امانت را می‌گیرد) | **Y** (ادامه) | |
| 5 | سینی با امانت به عقب (Y=0) برمی‌گردد | **Y** | Parcel on Tray |
| 6 | گنتری به محل تحویل (X=0, Z=400, جلوی نوار خروجی) می‌رود | **X+Z** | |
| 7 | نوار خروجی امانت را به کاربر می‌دهد | Conveyor | |
| 8 | گنتری به Home برمی‌گردد | **X+Z** | |

### جزئیات مرحله 4 — برداشت واقعی

> **نکته کلیدی (§6):** نوار جلوی خانه برای برداشت کافی نیست. مکانیزم Y با **لبه L شکل** سینی، امانت را به داخل سینی می‌کشد:
> - سینی کف تخت با لبه جلویی 30mm دارد.
> - هنگام ورود Y=450 به داخل خانه، کف سینی زیر امانت (با فاصله 5mm از کف خانه) قرار می‌گیرد.
> - هنگام برگشت Y=0، لبه جلویی امانت را به داخل سینی می‌کشد (اصطکاک کف سینی با نوار سیلیکونی).
> - برای بسته‌های سبک (<2kg) این کافی است؛ برای بسته‌های سنگین، **Push-Pull Finger** اختیاری روی سینی (Placeholder) پیش‌بینی شده.

## 4.3 دیاگرام توالی (Sequence Diagram)

```
Deposit:   User → Conveyor → Tray(Y=0) → Gantry(X,Z) → Tray(Y=450) → Eject → Tray(Y=0) → Home
Retrieval: User → Gantry(X,Z) → Tray(Y=450) → Collect → Tray(Y=0) → Gantry(Home) → Conveyor → User
```

## 4.6 تفاوت با طرح ساده "نوار جلوی خانه"

| طرح ساده (رد شده) | طرح واقعی (این پروژه) |
|-------------------|----------------------|
| نوار ثابت جلوی خانه‌ها | گنتری متحرک X/Z |
| امانت با جاذبه روی نوار می‌افتد (غیرقابل اعتماد) | سینی Y به داخل خانه می‌رود و امانت را می‌کشد |
| بدون کنترل ورود/خروج | Ejector + L-Edge کنترل‌شده |
| فقط برای بسته‌های کوچک | تا 15kg با اصطکاک سیلیکونی |
| برخورد با درب | Y فقط وقتی درب باز نیست — اما درب‌ها ثابت هستند، سینی از جلو وارد می‌شود (بدون نیاز به باز شدن درب) |

> **توضیح:** در این طراحی، درب‌های خانه‌ها **برای کاربر باز نمی‌شوند** — آن‌ها پنل‌های ثابت با برش دسترسی برای سینی هستند. سینی از بازشوی جلویی (بدون درب لولایی) وارد می‌شود. در صورت نیاز به درب قفل‌دار، درب به‌صورت کشویی کنار می‌رود (Placeholder برای نسخه آینده).
