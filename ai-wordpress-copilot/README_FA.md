# AI WordPress Copilot — دستیار هوشمند وردپرس

**سازنده وب‌سایت + توسعه‌دهنده وردپرس + متخصص سئو** در قالب یک افزونه وردپرس.

> نسخه 1.0.0 — وضعیت: کامل (۱۲ فاز) · ۳۱۰ تست خودکار سبز روی یک نصب واقعی وردپرس

---

## این افزونه چیست؟

یک **عامل هوش مصنوعی واقعی** (نه چت‌بات ساده) که با دستور زبان طبیعی فارسی یا انگلیسی، عملیات واقعی
روی سایت وردپرس شما انجام می‌دهد: صفحه می‌سازد، طراحی می‌کند، سئو را بررسی و اصلاح می‌کند،
محصولات فروشگاهی را مدیریت می‌کند و همه تغییرات را با امکان بازگردانی ثبت می‌کند.

یک دستور ساده مثل «**یک وب‌سایت فروشگاهی مدرن بساز**» باعث ساخت صفحات واقعی، قابل مشاهده و
قابل ویرایش می‌شود — همراه با برنامه اجرایی، بررسی سئو و گزارش تغییرات.

## امکانات کلیدی

| حوزه | قابلیت‌ها |
|---|---|
| **اتصال هوش مصنوعی** | هر ارائه‌دهنده OpenAI-sa (Base URL/کلید/مدل/هدرها/پارامترهای سفارشی)، تشخیص قابلیت مدل (tool calling، streaming، JSON mode، پنجره متن)، مدیریت خطاهای دقیق، retry/timeout/محدودیت نرخ |
| **گفت‌وگوی جریانی** | پاسخ لحظه‌ای (SSE)، نمایش مراحل ابزارها، برنامه اجرا، بازبینی خودکار، مصرف توکن، دکمه توقف، ادامه پس از قطعی |
| **سازنده وب‌سایت** | موتور طراحی (هدر/هیرو/فهرست/محصول/قیمت/نظرات/سؤالات/تماس/خبرنامه/گالری/لندینگ...)، سامانه طراحی متمرکز با تغییر زبان طبیعی («رنگ اصلی را سرمه‌ای کن»)، سازگار با دسکتاپ/تبلت/موبایل |
| **صفحه‌سازها** | گوتنبرگ (بلوک‌های واقعی) + المنتور (ساختار سازگار با نسخه نصب‌شده) — تشخیص خودکار با اولویت Elementor > Gutenberg > پوسته |
| **بازطراحی صفحه** | تحلیل صفحه ← استخراج محتوای مهم ← پیشنهاد طراحی ← پیش‌نمایش ← بررسی مشکلات ← اعمال پس از تأیید ← مقایسه قبل/بعد (بدون حذف محتوا بدون اجازه) |
| **سئو** | تحلیل صفحه/سایت، متادیتا، بررسی لینک‌های خارجی (کش/صف/همزمانی محدود/لغو/ادامه) + محافظ SSRF |
| **ووکامرس** | محصول ساده/متغیر، ویژگی‌ها، دسته‌ها، موجودی، تصاویر، تحلیل محصول، توضیحات + سئو، طراحی صفحه فروشگاه — **تأیید اجباری ادمین برای تغییر قیمت/موجودی** |
| **حافظه** | ذخیره/بازیابی/حذف واقعیت‌های سایت از طریق گفت‌وگو |
| **ایمنی** | صف تأیید ادمین، snapshot و بازگردانی، قفل اجرای همزمان، بدون ابزار اجرای PHP/Shell/SQL، گزارش امنیتی کامل |
| **رابط مدیریت** | بخش «سازنده وب‌سایت»، «گزارش‌ها»، تنظیمات کامل مدل/جریان/دستور سیستمی/مجوز ابزارها — همه دکمه‌ها فعال |

## نصب

1. فایل `dist/ai-wordpress-copilot.zip` را از مخزن دریافت کنید.
2. در پیشخوان وردپرس: **افزونه‌ها ← افزودن ← بارگذاری افزونه** ← انتخاب فایل ZIP ← **نصب** ← **فعال‌سازی**.
3. از منوی **AI Copilot ← API Connection** ارائه‌دهنده هوش مصنوعی خود را وارد کنید (Base URL + کلید API + مدل).
4. با دکمه «Test Connection» اتصال را بررسی و قابلیت‌های مدل را شناسایی کنید.
5. در **AI Chat** دستور بدهید: مثلاً «یک صفحه لندینگ مدرن برای محصولم بساز».

### پیش‌نیازها

- WordPress 6.0+ (PHP 7.4 به بالا — روی PHP 8.3 آزمون شده)
- برای فروشگاه: افزونه WooCommerce (اختیاری)
- برای صفحه‌ساز المنتور: افزونه Elementor (اختیاری)

## حریم خصوصی و امنیت

- کلید API شما فقط در پایگاه‌داده وردپرس ذخیره می‌شود و هرگز به مرورگر، HTML یا گزارش‌ها برنمی‌گردد.
- هوش مصنوعی **هرگز کد PHP/Shell/SQL اجرا نمی‌کند** — فقط از مجموعه ابزارهای کنترل‌شده استفاده می‌شود.
- تغییرات حساس (قیمت، موجودی، حذف) نیازمند تأیید صریح شماست و همه تغییرات با snapshot قابل بازگردانی‌اند.
