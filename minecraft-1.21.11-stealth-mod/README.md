# ماد فوق‌مخفی ماینکرافت جاوا ۱.۲۱.۱۱ فابریک (ویژه‌ی `play.trexmine.com` ، `Phoenix.GameUP.IR` و `smp3.mcsh.io`)
### هویت پوششی: `FerriteCore` (`ferritecore-dynamic-1.21.11-2.4.0.jar`)

این نسخه مخصوص **Minecraft Java Edition 1.21.11 (Fabric)** روی **TLauncher (تی‌لانچر)** با **تکنولوژی‌های جدید پرواز ۲۰۲۶ (بدون گذاشتن هیچ بلاکی)**، **اتوکلیکر متغیر ۳۰ تا ۵۰ CPS بدون اخطار چت (`T`)** و **X-Ray شامل تخت‌های بدوارز + ماب‌ها + لاوا + آب + سنگ‌های معدنی (`X` و `B`)** کامپایل شده است.

---

## ۱. جدول کامل کلیدهای مخفی و قابلیت‌ها

| کلید | عملکرد | جزئیات و تکنولوژی‌ها |
|---|---|---|
| **`V`** | **روشن / خاموش کردن پرواز ۲۰۲۶ (`Next-Gen Flight`)** | پرواز خالص در هوا (بدون گذاشتن بلاک) با استفاده از تکنولوژی **`BlockCollisionsMixin` (`Shapes.block()` Virtual Air-Collider)** + **`Vulcan 2.8.6 Setback Desync`**. با `W/A/S/D` در هوا روی یک کف فیزیکی نامرئی حرکت می‌کنی، با `Space` ارتفاع می‌گیری و با `Left Shift` پایین می‌آیی. |
| **`Ctrl + V`** | **تغییر تکنولوژی دور زدن آنتی‌چیت پرواز (۴ تکنولوژی ۲۰۲۶)** | چرخش بین ۴ تکنولوژی جدید: ۱) **حالت ۰ (پیش‌فرض — `Vulcan 2.8.6 Virtual Floor + Setback Desync`)**: ایجاد کف برخورد نامرئی `Shapes.block()` زیر پا در `BlockCollisionsMixin` و مسدود کردن پکت‌های عقب‌کشیدن سرور (`ClientboundPlayerPositionPacket`) در حین پرواز تا سرور مچ بدوارز نتواند تو را به جزیره برگرداند! ۲) **حالت ۱ (`Grim 2.3.73 Jan-2026 Ping-Queue + START_FALL_FLYING + Vulcan 2.7.7 Glide`)**: نگه‌داشتن موقت پکت‌های `ServerboundPongPacket` در `ConnectionMixin` به همراه ارسال پکت `START_FALL_FLYING` و گلاید متناوب `-0.10 / -0.155`. ۳) **حالت ۲ (`Grim 2.3.59 +1152 Unloaded-Chunk Offset`)**: جابه‌جایی مختصات پکت به چانک لودنشده (`+1152` بلاک) در لحظه‌ی ارسال تا موتور Simulation گریم چک حرکت را رد کند. ۴) **حالت ۳ (`Verus / Spigot 60 BPS Virtual-Floor Turbo`)**: پرواز ۶۰ بلاک بر ثانیه روی کف نامرئی به همراه `StatusOnly` Disabler. |
| **`T`** | **اتوکلیکر متغیر ۳۰ تا ۵۰ CPS (بدون اخطار چت‌باکس!)** | با زدن **`T`** روشن/خاموش می‌شود. در هوا هیچ پکت اضافه‌ای به سرور نمی‌فرستد، روی حریف با ریتم انسانی ۳۰ تا ۵۰ CPS نمونه‌برداری می‌کند و تمام اخطارهای چت CPS را فیلتر می‌کند. *(برای باز کردن چت از **`Enter`** یا **`/`** یا **`Ctrl + T`** استفاده کن).* |
| **`X`** | **X-Ray (تخت‌های بدوارز + سنگ‌های معدنی + چست‌ها)** | نمایش **تمام ۱۶ رنگ تخت (Bed) در بدوارز از پشت پشم/ابسیدین/چوب**، سنگ‌های معدنی، چست‌ها و اسپاونرها + روشنایی کامل بدون تغییر فایل `options.txt`. |
| **`B`** یا **`Alt + X`** | **گزینه نمایش ماب‌ها + لاوا + آب در X-Ray** | نمایش تمام لاواها، آب‌ها و پلیرها/ماب‌ها از پشت دیوار با هاله‌ی رنگی (`Glow ESP`). |
| **`Ctrl + X`** | **فیلتر دور زدن Anti-Xray سرور** | فقط سنگ‌های معدنیِ مجاور غار، هوا، آب یا لاوا را نشان می‌دهد. |
| **`Z` (نگه‌داشتن)** | **زوم ۴ برابر** | زوم نرم ۴ برابر روی سنگ‌های معدنی، تخت‌ها و پلیرهای دوردست. |
