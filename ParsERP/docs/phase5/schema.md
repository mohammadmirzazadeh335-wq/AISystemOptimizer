## منابع انسانی — `hr_*` (۱۲ جدول)

| جدول | نکتهٔ کلیدی |
|------|--------------|
| `hr_org_units` | درخت سازمانی، `parent_id`, `manager_employee_id`, `cost_center_id` |
| `hr_employees` | `code` یکتا، `person_id` یکتا (اشخاص `acc_details`)، حقوق پایه، بانک/شبا، `is_active` |
| `hr_employee_history` | نوع تغییر (واحد/عنوان/حقوق/قرارداد/وضعیت)، تاریخ اجرا، مقدار قبلی/جدید، کاربر |
| `hr_contracts` | `number` یکتا، نوع، بازه، حقوق پایه، ساعت/روز هفتگی، مزایا/کسور، `previous_contract_id` |
| `hr_shifts` | ساعت شروع/پایان، استراحت، مهلت مجاز، روزهای کاری، شیفت شب |
| `hr_employee_shifts` | اختصاص شیفت به کارمند با بازهٔ تاریخ |
| `hr_attendance` | یکتا `(employee_id, work_date)`؛ دقایق کارکرد/تأخیر/تعجیل/اضافه‌کار، منبع، تأیید |
| `hr_leave_types` | نوع، حقوق‌داری، نیاز به تأیید، سهمیهٔ سالانه، سقف ساعت |
| `hr_leave_requests` | `number` یکتا، بازه، روز/ساعت، وضعیت، تصمیم‌گیرنده |
| `hr_leave_balances` | یکتا `(employee_id, leave_type_id, period_year)`؛ سهمیه/انتقالی/تعدیل/استفاده‌شده |
| `hr_missions` | مقصد، بازه، هزینه، کمک‌هزینه، وضعیت، `payroll_applied` |
| `hr_overtime_requests` | یکتا `(employee_id, work_date)`؛ دقایق، تعطیل/عادی، وضعیت |

## حقوق و دستمزد — `pay_*` (۱۰ جدول)

| جدول | نکتهٔ کلیدی |
|------|--------------|
| `pay_settings_versions` | نسخهٔ تاریخ‌دار (`effective_from`/`effective_to`)، وضعیت، منبع/یادداشت |
| `pay_settings_items` | کلید/مقدار هر تنظیم در نسخه |
| `pay_tax_brackets` | پلهٔ مالیات: از، تا (تهی = بالاترین)، نرخ درصد |
| `pay_runs` | یکتا `(period_year, period_month)`؛ `settings_version_id`، جمع‌ها، `journal_id` |
| `pay_payslips` | یکتا `(run_id, employee_id)`؛ همهٔ اقلام جمعی، وضعیت، سند، پرداخت |
| `pay_payslip_lines` | اقلام فیش: نوع، عنوان، طرف (درآمد/کسور)، مبلغ، توضیح محاسبه |
| `pay_loans` | وام/مساعده، مبلغ، تعداد و مبلغ قسط، شروع بازپرداخت، وضعیت، پرداخت/سند |
| `pay_loan_installments` | یکتا `(loan_id, seq)`؛ سال/ماه سررسید، مبلغ، پرداخت‌شده، وضعیت، `slip_id` |
| `pay_batches` | دستهٔ پرداخت حقوق؛ تاریخ، صندوق/بانک، وضعیت، جمع‌ها، فایل بانکی، پرداخت/سند |
| `pay_batch_items` | یکتا `(batch_id, payslip_id)` و **یکتا `payslip_id`** — جلوگیری از پرداخت دوباره |

## دارایی ثابت — `ast_*` (۷ جدول)

| جدول | نکتهٔ کلیدی |
|------|--------------|
| `ast_categories` | نوع، سه حساب (دارایی/استهلاک/هزینه)، عمر و روش پیش‌فرض |
| `ast_assets` | `code` یکتا؛ سه حساب کپی‌شده از دسته، بهای تمام‌شده، اسقاط، عمر، روش، نرخ، کارکرد، وضعیت |
| `ast_movements` | انتقال/امانت‌دار/محل/وضعیت/سیاست با مقدار قبلی/جدید و کاربر |
| `ast_depreciation_runs` | یکتا `(period_year, period_month)`؛ وضعیت، تعداد، جمع، `journal_id` |
| `ast_depreciation_lines` | یکتا `(asset_id, period_year, period_month)`؛ ارزش آغاز، مبلغ، انباشته و ارزش دفتری پس از ثبت، کارکرد |
| `ast_disposals` | یکتا `asset_id`؛ نوع، مبلغ فروش، ارزش دفتری، سود/زیان، سند و رسید |
| `ast_maintenance` | نوع، هزینه، پیمانکار، مصرفی، سرویس بعدی، پیوست |
