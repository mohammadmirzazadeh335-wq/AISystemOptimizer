- **آیا ارتباط بین ماژول‌ها درست کار می‌کند؟** برای مسیرهای موجود (خرید/فروش ← انبار ← حسابداری، دریافت ← خزانه ← حسابداری، استهلاک ← حسابداری): هر عملیات دقیقاً یک سند حسابداری و یک سند انبار می‌سازد و شکست وسط کار هیچ رکورد ناقصی باقی نمی‌گذارد. مسیرهای تولید/پروژه/واردات/پخش **وجود ندارند**.
- **آیا مجوزها به‌درستی اجرا می‌شوند؟** بله در لایهٔ سرویس، و از این فاز نشستِ پایان‌یافته/قفل‌شده هم رد می‌شود.
- **آیا اطلاعات در برابر ثبت تکراری و هم‌زمانی محافظت شده‌اند؟** بله برای اسناد حسابداری، فاکتورها، دریافت/پرداخت و موجودی: قید یکتای پایگاه داده + کلید تکرار + بازیابی شماره. هم‌زمانی روی SQLite آزمون شد؛ رفتار PG باید جداگانه سنجیده شود.
- **آیا بازیابی نسخه پشتیبان آزمایش شده است؟** بله، واقعاً: پشتیبان ← خرابی سه‌گانه ← بازیابی ← تطابق کامل ارقام گزارش‌ها و ترازنامه.
- **آیا نرم‌افزار برای فاز سوم دیباگ آماده است؟** برای ماژول‌های موجود و روی SQLite: **بله، با شرایط**: (۱) آزمون PostgreSQL، (۲) تأیید نرخ‌های قانونی، (۳) تصمیم دربارهٔ رمزنگاری پشتیبان، (۴) تعیین تکلیف فاز ۶.
  هیچ آزمونی که اجرا نشده موفق اعلام نشده و هیچ قابلیتی که وجود ندارد «آماده» گزارش نشده است.
